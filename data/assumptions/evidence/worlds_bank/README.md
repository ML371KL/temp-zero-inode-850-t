# worlds_bank — банковская надстройка миров (A-M3, MODEL §3.1, прил. B)

`build_overlay.py` собирает `data/assumptions/worlds_bank.json` из листа надстройки этапа 1
(`inputs/bank_overlay_draft.yaml` — копия листа, имена локальных папок заменены относительными путями; `--sync` обновляет
копию из `$BANK_HANDOFF_DIR`, `--check` — сверка). Хэш файла вписывает в книгу `build_assumptions.py`
(`worlds.overlay.sha256`); ядро сверяет файл с этим хэшем.

Рост сектора у банков семейства один, поэтому файл обязан совпасть с надстройкой книги Сбербанка бит в бит
(sha256 6fb82a41…) — скрипт предупреждает, если это не так. Лист этапа 1 несёт готовые пути по мирам; скрипт их не
пересчитывает, а проверяет: мир N — середины диапазонов базового сценария «Основных направлений денежно-кредитной
политики» (проект 30.09.2026, табл. 3.2, PDF-с. 73, sha256 3c3270ef…) и прогноза Банка России по балансам («Банковский
сектор. II кв. 2026», PDF-с. 20) для «прочей розницы» 2026–2027 годов; 2028–2029 — (население − w·ИЖК)/(1 − w),
w = 0,5806; миры H и M — реальный рост базы при инфляции своего мира (g_W = (1 + g_N)(1 + π_W)/(1 + π_N) − 1);
средства физлиц и бизнеса — денежная масса М2; годы 2026–2029, дальше ядро сводит рост к g_T мира к `volumes.lt_from`
(2033).

| Мир | Кредиты бизнесу 2026 / 27 / 28 / 29 | Ипотека | Прочая розница | Средства (М2) |
|---|---|---|---|---|
| N | 9,0 / 9,5 / 10,5 / 10,5 % | 8,0 / 9,5 / 12,5 / 12,5 | 6,0 / 5,5 / 7,7 / 7,7 | 9,5 / 8,5 / 9,5 / 9,5 |
| H | 9,0 / 10,9 / 12,7 / 12,3 | 8,0 / 10,9 / 14,7 / 14,3 | 6,0 / 6,9 / 9,9 / 9,5 | 9,5 / 9,9 / 11,7 / 11,3 |
| M | 9,0 / 9,8 / 13,9 / 16,6 | 8,0 / 9,8 / 16,0 / 18,7 | 6,0 / 5,8 / 11,0 / 13,6 | 9,5 / 8,8 / 12,9 / 15,5 |

Премии роста Т к сектору в надстройку не входят — это ключи книги (`volumes.loan_share_drift`, `funds_share_drift`).
История премий (блоки `t_premium`, `funds` листа): прочая розница +15,2 п.п. за 12 месяцев до 30.06.2026 и +11,1 за
полугодие в годовом выражении; ипотека −0,9 и +4,6; бизнес +37,4 и +20,0; средства клиентов −3,5 п.п. за 2025 год и +0,6
за 12 месяцев. Ряд сектора «прочая розница» — необеспеченные потребительские кредиты без автокредитов; у Т авто — треть
группы, разницу (около 1,3 п.п. роста базы) несёт премия.
