# regulation — полы и требования сценариев капитала (A-K2b–A-K4b, MODEL §3.3, §4.12, §4.13)

`floors.py` считает полы нормативов по траекториям надбавок книги и сверяет их с регуляторным графиком этапа 1
(`inputs/stage1/regulation/schedule.yaml`: Инструкция 220-И пп. 2.2, 3.2, 3.4; решения Банка России 08.11.2024 и
27.07.2026; доклады о системно значимых банках 22.05.2025 и 20.02.2026 — документы с sha256 в самом графике) и с
таблицей листа капитала (`inputs/stage1/calib/capital/out/p3_floors.csv`). Запас менеджмента графика этапа 1 (2,0 п.п.)
устарел и не читается: запас книги — 1,5 п.п.

| Сценарий | Пол Н20.0 2026 / 27 / 28 / 29 / с 2030 | Пол Н20.1 | Требование Н20.0 (пол + запас 1,5) |
|---|---|---|---|
| По графику | 10,00 / 10,75 / 12,00 / 12,00 / 12,00 % | 6,50 / 7,25 / 8,50 / 8,50 / 8,50 | 11,50 / 12,25 / 13,50 / 13,50 / 13,50 |
| Средняя группа СЗКО | 10,00 / 10,75 / 12,50 / 13,00 / 13,00 | 6,50 / 7,25 / 9,00 / 9,50 / 9,50 | 11,50 / 12,25 / 14,00 / 14,50 / 14,50 |
| Жёсткий (вычет 0,3 п.п. с 2028) | 10,00 / 10,75 / 12,50 / 13,00 / 13,50 | 6,50 / 7,25 / 9,00 / 9,50 / 10,00 | 11,50 / 12,25 / 14,00 / 14,50 / 15,00 |

Требование с глиссадой (8 кварталов вперёд, 0,25 п.п. за квартал), 3-й квартал 2026 — 2-й квартал 2028: «по графику»
12,00; 12,25; 12,50; 12,75; 13,00; 13,25; 13,50; 13,50 % — пример договора ключей воспроизведён; «средняя группа» и
«жёсткий» — 12,50 → 14,00 %. Прирост требования за квартал нигде не больше шага глиссады: ступени минимума 01.01.2027 и
01.01.2028 набираются заранее. До 2028 года сценарии совпадают: расходятся только суждения о надбавке за системную
значимость и антициклической надбавке после 2028 года.
