# nii — книги ЧПД, передача ставки, цель и ближний путь ЧПМ, полы спредов (A-N*, A-C4b, A-X8)

```
python -B data/assumptions/evidence/nii/nii_book.py    # → out/nii_book_out.json (код 1 — расхождение с шаблоном книги)
```

Лист калибровки ЧПД этапа 1 (оценки ρ, β и спредов по истории ставок двенадцати книг, решатель сдвига σ0 и сжатия φ,
пробный квартальный проход пути ЧПМ) считался на коде и данных книги-образца как носителе и в репозиторий целиком не
перенесён: его выходы лежат малыми входами (`inputs/stage1/calib/nii/out/`, sha256 — `inputs/SOURCES.json`). `nii_book.py`
повторяет независимо всё, что выводится из фактов якоря и записи миров, считает из входов правило суждения о марже,
цену недостающего фондирования и порог гейта стоимости средств клиентов и сверяет шаблон книги; доли раскладки, ближний
сдвиг и концы осей выводит на ядре `path/derive_on_engine.py` (уровень маржи и премия роста средств клиентов — суждения
книги, на ядре они не выводятся).
