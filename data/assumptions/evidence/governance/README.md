# governance — дисконт за управление по каналам (A-V7, MODEL §8.2)

```
python -B data/assumptions/evidence/governance/governance_book.py   # → out/governance_out.json (код 1 — расхождение с шаблоном книги)
```

Лист каналов этапа 1 читает десятки строк отчётности, ряды цен и снимки биржи и в репозиторий целиком не перенесён: его
выходы лежат малыми входами (`inputs/stage1/calib/governance/out/`). `governance_book.py` сверяет шаблон книги с
предложением листа и повторяет арифметику ключа: рублёвый канал переводится в долю капитала модели неподвижной точкой
g = PV / (PV + медиана × делитель − объявленный дивиденд); при PV = 0 ключ равен нулю при любой медиане выпуска.
