# pnl — операционный базис, мосты, связи с объёмом, налог, пакет Яндекса, доля выплаты (A-F*, A-O*, A-T*, A-D1)

Перенесённый лист калибровки этапа 1 и лист сверки с книгой.

```
python -B data/assumptions/evidence/pnl/run_all.py     # шаги 1–5 листа этапа 1 → out/*.csv, out/*.json, out/sN_out.txt, предложение ключей
python -B data/assumptions/evidence/pnl/pnl_book.py    # сверка шаблона книги → out/pnl_book_out.json (код 1 — расхождение)
```

`run_all.py` (`pnl_lib.py`, `s1_op_basis.py` … `s5_proposal.py`) — код этапа 1 с заменой корня путей; на малых входах его
выходы совпадают с выходами этапа 1 байт в байт. Шаг 1 берёт у ядра функцию годовой суммы траектории
(`model.cell._year_sum_table`); шаг 3 читает надстройку миров книги (`data/assumptions/worlds_bank.json`).
